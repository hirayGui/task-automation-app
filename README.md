# Task Automation App

Aplicação desenvolvida em **Python** com foco em **automação de tarefas**, criação de bots e automação de processos utilizando técnicas de **RPA (Robotic Process Automation)** e **Web Scraping**.

O projeto foi desenvolvido como uma iniciativa pessoal com o objetivo de aprofundar meus conhecimentos em Python aplicado à automação, além de servir como projeto de portfólio.

---

## 🚀 Funcionalidades

* **Automação de tarefas** — automatização de processos repetitivos para reduzir o trabalho manual.
* **Criação de bots** — desenvolvimento de bots para execução automatizada de tarefas.
* **RPA** — automação de processos que normalmente seriam realizados manualmente.
* **Web Scraping** — coleta e processamento automatizado de informações disponíveis na web.
* **Otimização de tempo** — redução do tempo gasto em tarefas operacionais e repetitivas.

---

## 🛠️ Tecnologias

* **Python**
* **CSV** — utilizado como fonte de dados para criação e manipulação do DataFrame.
